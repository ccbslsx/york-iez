# York IEZ 约克公建云多联机 · Home Assistant 集成

把 **约克（York）IEZ 聚好看多联机 / 公建云多联机**接入 Home Assistant。
一台室外机下面挂多台室内机，每台内机 = 一个 `climate` 实体，附带地暖开关、
室内温度传感器和故障检测。

> 本集成**不是**官方出品，接口逆向自「约克智慧家」App。它与
> [`york_smart_home`](https://github.com/zhangluu520/york_smart_home)（面向 XKQ 线控器）
> 是两套不同协议，请勿混用。

## 功能

- **制冷 / 制热 / 地暖 / 送风 / 除湿 / 自动** 模式切换（见[已知限制](#已知限制)）
- 目标温度（16–32 °C，1 °C 步进）
- 四档风量：自动 / 低 / 中 / 高
- 每台内机的 **地暖开关**（`mode=16`，与热泵制热是两套物理系统）
- **室内温度** 传感器（回风温度，可进长期统计）
- **故障** 二进制传感器 + 机组故障汇总
- 机组卡片显示 **外机型号 / 固件版本 / 在线状态**
- 设备树：1 个机组设备 + N 个内机设备（父子结构）
- 登录态自动续期，新 token 回写本地条目（重启不用重新登录）
- 轮询间隔可调（选项里改，即时生效）
- 支持「重新认证」流程，改密码后无需删除重建
- 一键导出诊断信息（自动打码手机号 / 密码 / token / 序列号）

## 实体

以 6 台内机为例，共 **1 个机组 + 6 个内机 = 7 个设备、27 个实体**：

| 设备 | 实体 | 类型 |
|---|---|---|
| 机组 | 在线 | `sensor` |
| 机组 | 故障汇总 | `sensor` |
| 机组 | 外机型号 | `sensor`（诊断） |
| 每台内机 | 空调（房间名） | `climate` |
| 每台内机 | 地暖 | `switch` |
| 每台内机 | 室内温度 | `sensor` |
| 每台内机 | 故障 | `binary_sensor` |

内机设备名取自约克 App 里的房间名。你在 App 里改名，HA 重启后会自动同步。

## 安装

### HACS（推荐）

1. HACS → 右上角 ⋮ → **自定义存储库**
2. 仓库填 `ccbslsx/york-iez`，类型选 **Integration**
3. 搜索「York IEZ」→ 下载
4. **重启 Home Assistant**

### 手动

把 `custom_components/york_iez/` 整个目录拷到 HA 配置目录下的
`custom_components/` 里，然后重启。

## 配置

设置 → 设备与服务 → 添加集成 → 搜索 **York IEZ** → 填约克智慧家 App 的
**手机号 + 密码**。

- 同一个家庭（homeId）只允许一个条目，重复添加会提示「已配置」。
- 改密码后：集成卡片 → ⋮ → **重新认证**，填新密码即可。
- 想改轮询间隔：集成卡片 → **配置** → 填秒数（15–600，默认 60）。

## 数据来源与隐私

| 项目 | 位置 |
|---|---|
| 手机号 / 密码 / 登录 token | 只存在你的 HA 配置目录 `.storage/core.config_entries` 里 |
| 集成源码 | **不含任何账号信息**，仓库里也没有硬编码凭据 |
| 诊断导出 | 手机号、密码、token、序列号、网关编号全部自动打码 |
| 网络请求 | 只发往约克云 `1app.hicloud.hisensehitachi.com` |

凭据**不会**发到作者或任何第三方。

## 已知限制

这些限制来自设备本身/云端协议，不是集成没做：

- **风量只有 4 档**（自动/低/中/高），没有 7 档
- **模式只有制冷(1)/制热(4)/地暖(16)** 三种确定可用；`送风(2)`、`除湿(8)`、`自动(0)`
  沿用厂商常量，未在所有机型上实测。若云端拒绝，HA 会弹出错误提示
- **1 °C 步进**，不支持半度
- **没有摆风 / 导风板 / 人感 / PM2.5 / 滤网 / 自清洁 / 除霜 / 辅热 / 按键锁 / 背光**
  —— 这些都是 XKQ 线控器面板的功能，IEZ 网关没有对应字段
- **外机没有运行参数**（频率/压力/电流），云端状态接口只接受内机 ID
- 湿度字段存在但恒为 0（机器未装湿度传感器）
- 地暖模式的「室内温度」仍取回风温度；盘管水温单独放在属性里

## 排错

| 现象 | 处理 |
|---|---|
| 集成提示 `invalid_auth` | 确认用的是约克智慧家 App 的账号；若 App 里改过密码，走「重新认证」 |
| 实体变 `unavailable` | 云端或网关离线。看「在线」传感器的属性和日志 |
| 控制没反应 / 报错 | 看 HA 日志里 `york_iez` 的记录；约克云对同一账号的并发登录较敏感 |
| 状态更新慢 | 调小轮询间隔（选项），但建议不低于 30 秒 |
| 其他问题 | 下载诊断（打码后）再提 issue |
